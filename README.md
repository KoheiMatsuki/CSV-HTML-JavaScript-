# mdBuild

Markdownファイルを単一のHTMLファイルに変換するビルドツール。Markdown本文中でCSVファイルを参照すると、ビルド時にそのCSVから直接HTMLテーブルを生成して埋め込む。

設計方針の詳細は [設計方針.md](./設計方針.md) を参照。

## セットアップ

```sh
npm install
```

## 使い方

```sh
node build.js <入力.md> [出力.html]
```

- 出力パスを省略した場合、入力ファイルと同じディレクトリに拡張子を`.html`に変えて出力する。
- 例:

```sh
node build.js sample.md
# -> sample.html が生成される

node build.js sample.md out/result.html
# -> out/result.html に出力される
```

## CSVを表として埋め込む

mdファイル中に、以下の形式のコメントを1行だけで記述すると、その位置にCSVの内容がHTMLテーブルとして展開される。

```
<!-- csv: 状態遷移.csv -->
```

- パスは **md自身のディレクトリ** を基準に解決される。
- CSVの1行目はヘッダー行として扱われる。
- 2行目以降は、先頭列を行見出し、残りをセル値として扱う。値が`-`のセルは「遷移なし」として薄い色で表示される。

### 例

`sample.md`:

```markdown
# 状態遷移表

<!-- csv: 状態遷移.csv -->
```

`状態遷移.csv`:

```csv
,0x0001,0x0002,0x0003
10秒経過,0x0002,-,-
20秒経過,-,0x0003,-
```

`node build.js sample.md` を実行すると、見出しと表が描画された自己完結型の`sample.html`が生成される。

## エラー時の挙動

参照しているCSVファイルが見つからない・読み込めない場合、ビルドはエラーメッセージを表示して失敗する（終了コード1）。壊れた表を含むHTMLは出力されない。

## 制約・スコープ

- 単一ファイルの変換のみに対応。ディレクトリ一括ビルドやwatchモードはサポートしていない。
- CSVはシンプルなカンマ区切り形式のみに対応（クォートや値中のカンマは非対応）。
- ファイル名にスペースを含むCSVパスの指定は未対応。
